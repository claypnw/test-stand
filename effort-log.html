Effort log

What each job costs to run, day by day: how many times it ran, how many minutes it took, and how much it read in and wrote out, in tokens. A token is a small piece of a word — the meter Muse's work is counted in.

How to read the token counts: "read in" counts the standing pages a job reads again at every step, so a long job's count runs into the millions without meaning millions of new words. Some jobs run with no agent and leave no token record; those lines say so. Your plan's own meter — the weekly percent — does not split by job, so it is not on this page.
