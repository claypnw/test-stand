2 · The word test

A listing is kept only when its own words pass this test. Each row is one word or phrase. Tick NOT to ban a row's word. The joiner between two rows says how they combine. The ( and ) buttons group rows together. A term with more than one word is sent as one phrase, in quotes.

3 · The place

ZIP code Radius, in miles
Every search centers on the ZIP code you type here — never on where you are. You might search a Phoenix ZIP today because you will be in Phoenix tomorrow. The program never asks for or uses your own location.

4 · The stores

Only stores whose inventory can be searched online stand in this box — a store with no online inventory, like a thrift store or Goodwill, is never included, however near it is. If you change the ZIP or the radius, the store list for the new pair is gathered when the search is run.

Stores this program cannot search

Some retailers do not allow this program to view their inventory, and they are named here so a missing store is never a mystery. Amazon is first on the list: it refuses automated access from this machine — checked November 16, 2026 — so no Amazon listings ever stand in a run's results. Every run's results page also carries a Copy-this-search box: the same search in Amazon's own style, ready to paste into Amazon's search box by hand. Any other store that refuses a run is named in that run's results, in the same plain words.
