## Conventions
Add an entry whenever you work something out worth keeping, for example:

Long jumps across a chart use connectors — small circles with matching letters — never long lines crossing other boxes. Standard symbols per ANSI/ISO: terminator = start/stop, rectangle = one step, diamond = a question with the answers on the arrows.
