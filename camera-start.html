House Cameras — Start Here

This one page holds everything for watching the house cameras. Keep it. Open it every time.

On your PC — do this first, every time

  1. The camera program, go2rtc.exe, stands in your Downloads\test folder. If it is ever missing, get it from the maker's page: go2rtc releases page — the file is named go2rtc_win64.zip.
  2. First time only: save these two files into that same Downloads\test folder. Right-click each name, then click Save link as.
    go2rtc.yaml — the settings for all ten cameras.
    start-cameras.bat — the start file.
  3. First time only: the settings file holds the words <RECORDER-PASSWORD> where your camera box password goes. Open go2rtc.yaml in Notepad, use Replace All to swap those words for your password in its coded form (@ is %40, ! is %21, # is %23), and save. Muggy does not hold your password, so it is not written in any file here.
  4. Every time: double-click start-cameras.bat. A black window opens. Leave it open the whole time you watch. The camera page opens in Chrome on its own.
  5. To stop: close the black window.

On your phone or tablet

  1. Join the home Wi-Fi. The PC steps above must be done first, with the black window open.
  2. The cameras open at an address that holds your PC's own home address. To read that address on your PC: hold the Windows key, tap R, type cmd, tap Enter, type ipconfig, tap Enter, and read the line IPv4 Address — it starts 192.168.7.
  3. Type that address in this box and tap the button. The cameras open on this screen.
